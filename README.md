# Task List App

A simple web app to manage your daily tasks.

## How to Use

1. Open `index.html` in your web browser
2. Type a task in the input field
3. Click "Add" button
4. Mark tasks as done with the checkbox
5. Delete tasks with the delete button
6. Use filter buttons to view different task types

## Features

- Add new tasks
- Mark tasks as complete
- Delete tasks
- Filter tasks (All, Completed, Not Completed)
- Tasks are saved automatically

## Files

- `index.html` - Main app file
- `styles.css` - App styling
- `script.js` - App functionality

## Run the App

Just open `index.html` in any web browser.
